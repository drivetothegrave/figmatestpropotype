# Changelog

Все заметные изменения библиотеки документируются в этом файле.

## [1.5.8] — 2026-09-29
### Исправлено
- Исправлены пути деклараций типов для icon subpath-экспортов в npm-пакете.
- Расширены проверки CommonJS/ESM-экспортов и типов для наборов иконок.

## [1.5.7] — 2026-09-28
### Добавлено
- Добавлен отдельный набор `20/Stroked1px` с иконками `InformationCircle`, `KonturTalk` и `QuestionCircle`.

### Изменено
- `QuestionCircle` перенесена из общего набора иконок и `20/Stroked` в `20/Stroked1px`. Замените импорт `import { QuestionCircle } from '@pluginwoman/t-ds/icons'` на `import { QuestionCircle } from '@pluginwoman/t-ds/icons/20/Stroked1px'`.
- В генерируемые CommonJS-файлы добавлено точечное разрешение `@typescript-eslint/no-require-imports`; загрузка через `require()` сохранена.
- Перед публикацией проверяются `.cjs` файлы из npm-архива, CommonJS и ESM экспорты и декларации типов.

## [1.5.6] — 2026-09-26
### Исправлено
- Выровнены help-иконки в `Dropdown` и `Input`.
- Скорректированы отступы и выравнивание разделителей в `ActionSheet` и `FormCell`.

### Изменено
- Обновлено preview-описание контролов форм.

## [1.5.5] — 2026-09-24
### Исправлено
- Уточнены отступы, стилизация и API `DropdownPopup`.
- Скорректированы размеры иконок в `ContextualNotification`, `NavigationBar`, `WidgetTitle`, `Cell` и `LinkCell`.
- Исправлены стили `PageAction`.

### Изменено
- Дополнительные гайды `AGENTS.tokens.md`, `AGENTS.components.md` и `AGENTS.icons.md` теперь входят в npm-пакет.

## [1.5.4] — 2026-09-17
### Добавлено
- Добавлен явный entrypoint стилей `@pluginwoman/t-ds/style.css` с сохранением алиаса `style`.

### Исправлено
- Восстановлены корректные отступы опций в `Dropdown`.

### Документация
- Обновлены инструкции по установке, registry и доступным экспортам компонентов.

## [1.5.3] — 2026-09-09
### Исправлено
- Уточнены отступы и отображение иконки в `AccordeonCell`.
- Восстановлены корректные координаты 16px Stroked-иконок.
- Исправлены цвета неактивных шагов в `NavigationBar`.

### Изменено
- Обновлены demo-превью страниц и `PageLayout`.

## [1.5.2] — 2026-08-28
### Исправлено
- Исправлены внутренние отступы и поведение скроллбара в `Modal`.
- Клики по `Checkbox` и `Radio` внутри `Cell` больше не всплывают до родительской ячейки.
- В demo добавлена проверка изоляции кликов управляющих элементов.

## [1.5.1] — 2026-08-28

### Исправлено

- Уточнены боковые отступы promo-страницы на адаптиве.
- Убран лишний `max-width` у `PromoPageBanner` для корректного растягивания в контейнере.

## [1.5.0] — 2026-08-28

### Добавлено

- Добавлен вариант `PromoPageBannerAib` для AIB-промо-сценариев.
- В demo добавлены preview AIB-баннера и обновлённых promo-сценариев.
- Добавлен цветовой токен `warning-dark` для текста предупреждений.

### Изменено

- `PromoPageBanner` и `PromoPageCta` обновлены для новых вариантов композиции и success-состояния.
- `Cell` и его аксессуары корректно работают с многострочным контентом и интерактивными состояниями.

## [1.4.6] — 2026-08-25

### Добавлено

- Добавлены новые наборы Filled/Stroked-иконок размеров 16, 24 и 32 px и публичные subpath-экспорты.
- Preview иконок расширен для всех доступных размеров и начертаний.

### Изменено

- `MainPageNavigationBar` переведён на системный компонент `Avatar` для отображения клиента.
- Обновлена документация по импорту иконок.

## [1.4.5] — 2026-08-20

### Исправлено

- Уточнены отступы `PromoPageSteps` и состояния hover для белых `Button` и `IconButton`.

## [1.4.3] — 2026-08-19

### Исправлено

- Убран лишний внутренний отступ в mobile-версии `PromoPageBanner`.
- Уточнены радиусы visual-блоков `PromoPageSteps` для desktop и mobile.

## [1.4.2] — 2026-08-19

### Исправлено

- Исправлено размещение success-изображения в `PromoPageCta` на desktop и mobile.
- Уточнены отступы в `PromoPageSteps` и финальной CTA-секции промо-лендинга.

## [1.4.1] — 2026-08-18

### Исправлено

- Patch-релиз для синхронизации версии пакета и lockfile перед публикацией.

## [1.4.0] — 2026-08-18

### Добавлено

- В `Widget` добавлены варианты `filled` и `outlined`.
- Добавлен проп `isOutlinedOnAdaptive` для сохранения обводки `Widget` на адаптивных экранах.
- В demo добавлены контролы для проверки вариантов `Widget`.

### Изменено

- `Avatar` теперь использует системные `ts-*` стили для текста label вместо ручной типографики.
- Уточнён вертикальный отступ между содержимым `Cell`.
- Обновлён гайд по сборке и проверке promo pages.

## [1.3.0] — 2026-08-14

### Добавлено

- Добавлены публичные `scrollToElement` и `useScrollTo` для плавной прокрутки к DOM-элементу, React ref или CSS-селектору.
- В `Footer` добавлен проп `isVisible` со стандартной анимацией показа/скрытия и поддержкой `prefers-reduced-motion`.
- Добавлены промо-компоненты `PromoPageCta`, `PromoPageSteps` и `PromoPageTitle`.
- Добавлен standalone-пример промо-лендинга в demo.
- Добавлена маска телефона для `Input` и вариант `white`.
- Добавлены маркетинговая палитра и типографика Tochka Script.

### Документация

- Обновлён каталог компонентов, README и примеры применения новых API.
