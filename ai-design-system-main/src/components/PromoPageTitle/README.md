# PromoPageTitle

Заголовок промо-страницы с адаптивной типографикой:

- desktop: `ts-600-5xl`;
- адаптив до `1023px` включительно: `ts-600-3xl`.

## Props

| Проп | Тип | По умолчанию | Описание |
|---|---|---|---|
| `children` | `React.ReactNode` | `'Text 5XL'` | Текст заголовка |
| `className` | `string` | `''` | Дополнительный CSS-класс |
